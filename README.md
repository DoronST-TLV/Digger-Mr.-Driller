# Strata

A vertical-descent digging game — the Digger (1983) idea with Mr. Driller's rules — built in Unity 6.3 LTS for the Unity 101 final project at Tel Aviv-Yafo Academic College.

Dig down. Removing one block removes its whole colour group. Anything left unsupported shakes, then falls — and can crush you. Falling groups that merge into 4+ of the same colour clear and start a chain. Air runs out; capsules refill it. One life. How deep can you go?

**Design document:** [GDD.md](GDD.md) · **Work plan:** [PLAN.md](PLAN.md)

## Controls
- PC: arrow keys / WASD (left, right, down), Esc = pause
- Phone: tap left / right / below the digger, Back = pause

## Running
- Open the project in Unity **6000.3.22f1**, open `Assets/_Project/Scenes/Game.unity`, press Play.
- Builds: menu **Strata → Build Windows** / **Strata → Build Android APK** (output in `Builds/`, not committed). Downloads are on the Releases page.

## Project layout
```
Assets/_Project/
  Scripts/   runtime code (namespace Strata)
  Editor/    SceneBuilder (creates the scene + prefabs from code), BuildScript, import rules
  Art/       own sprites (PNG)
  Audio/     own sound effects (WAV)
  Config/    GameConfig.asset — every tunable number
  Prefabs/   Block, Player, ClearBurst (generated by SceneBuilder)
  Scenes/    Game.unity (generated by SceneBuilder)
```

## Patterns used (course requirements)
- **Singletons:** GameManager, BlockPool, BurstPool, AudioManager (persistent)
- **Object pools:** BlockPool (`ObjectPool<Block>`), BurstPool (`ObjectPool<ParticleSystem>`)
- **Coroutines:** fall/merge cascade, player movement, block shake and squash, game-over flow
- **ScriptableObject:** GameConfig
- **Events:** C# events between GridManager / PlayerController / GameManager and the UI + juice layer
- **Mobile:** portrait, touch input, safe area, pause on background, Android build
